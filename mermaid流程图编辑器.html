📊 Mermaid 流程图编辑器

一款基于浏览器的实时 Mermaid 流程图编辑器，支持代码编辑、实时预览、双击修改节点、画布拖拽缩放、超清 PNG 导出，以及 IDEA 风格代码编辑器。

✨ 核心特性

  • 📝 IDEA 风格编辑器：基于 CodeMirror 的深色主题（Dracula），支持 Mermaid 语法高亮、自动缩进、括号匹配。
  • 🔍 实时预览：左侧编写代码，右侧 SVG 流程图实时渲染，无延迟。
  • ✏️ 双击编辑节点：直接双击流程图节点文本，快速修改内容并同步代码。
  • 🖱️ 画布拖拽与缩放：鼠标拖拽平移视图，Ctrl+滚轮 大步缩放，Shift+滚轮 微调比例。
  • 🖼️ 超清 PNG 导出：根据 SVG 原始尺寸动态计算像素比（最小宽度 2400px），自动添加 40px 白色边距，保证放大后依然锐利。
  • 📏 面板拖拽调整：中间分隔条可随意拖拽，分配代码与预览区域宽度。
  • 🖥️ 全屏预览模式：一键进入全屏，专注查看流程图结构。
  • 📄 双标签页：内置 README 文档，无需额外文件即可了解使用方法。

🚀 快速开始

  1. 下载或保存本 HTML 文件到本地。
  2. 双击用浏览器打开（推荐 Chrome、Edge 等现代浏览器）。
  3. 在左侧面板输入或修改 Mermaid 流程图代码。
  4. 右侧实时显示流程图，支持拖拽、缩放、双击编辑。
  5. 点击右上角按钮可放大/缩小/重置视图或进入全屏。
  6. 点击 导出超清 PNG 下载高清图片，或按 Ctrl+S 快捷键。

📦 技术栈

  • Mermaid.js - 流程图渲染引擎
  • CodeMirror - 代码编辑器
  • 原生 Canvas API - PNG 导出与超清缩放
  • 纯 HTML/CSS/JavaScript，零依赖构建工具

📌 导出说明

导出的 PNG 图片宽度至少 2400 像素，并带有 40px 白色边距，适合直接插入文档、演示文稿或网页，放大不失真。导出过程使用离屏 Canvas 绘制，不受当前预览缩放影响。

🔧 自定义配置

您可以修改代码中的以下变量来调整行为：

const EXPORT_PADDING = 40;   // 导出图片边距（px）
const MIN_WIDTH = 2400;      // 导出最小宽度
const BIG_STEP = 0.1;        // Ctrl 缩放步长
const SMALL_STEP = 0.02;     // Shift 缩放步长

📝 注意事项

  • Mermaid 代码语法请参考 官方文档。
  • 全屏模式基于浏览器 Fullscreen API，部分浏览器可能需要用户手动操作。
  • 如果流程图特别复杂，导出时间可能稍长，请耐心等待。
